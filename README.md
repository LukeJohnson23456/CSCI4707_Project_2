# CSCI4707_Project_2
Quinn Daly, Zachary Farrell, Luke Johnson, Ryan Mattson

This project creates a database in SQL for the relational schema from assignment 1. Each of the 11 tables
which were in the relational schema have a CREATE TABLE SQL script which have been verified to run in mySQL.

Note that there were a couple mistakes with the relational schema from assignment 1, and these have been
corrected for this assignmnet, meaning the scripts are based on the corrected assignment 1.

The order in which table are created is below.
1. CUSTOMER
2. PAYMENT
3. BOOK
4. AUTHOR
5. EMPLOYEE
6. ORDER_
7. INVENTORY
8. BOOK_ORDER
9. WRITES
10. ASSISTS_CUSTOMER
11. MANAGE_INVENTORY
